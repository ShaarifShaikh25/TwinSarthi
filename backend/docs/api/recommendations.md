# Human-in-the-Loop Recommendation Decisions API

## 1. Overview
Automated AI recommendations in mission-critical polar environments require explicit human review and authorization. POLAR-TWIN implements a full decision lifecycle with immutable audit trails.

---

## 2. Decision Workflow & Statuses

```
   PENDING (generated by AI/Risk Engine)
      │
      ├──> [CONTROLLER / ADMIN] -> APPROVE ──> APPROVED
      │
      ├──> [CONTROLLER / ADMIN] -> MODIFY  ──> MODIFIED
      │
      └──> [CONTROLLER / ADMIN] -> REJECT  ──> REJECTED
```

---

## 3. Endpoints

### 3.1 List Recommendations
`GET /api/recommendations?station_id=1&status=pending`

Lists recommendations awaiting human-in-the-loop review.

---

### 3.2 Ingest / Create Recommendation
`POST /api/recommendations`

Invoked by the AI / Risk engine to present an actionable operational suggestion.

#### Request Body
```json
{
  "station_id": 1,
  "title": "Shift Non-Essential Heating Load to DG 2",
  "category": "ENERGY_OPTIMIZATION",
  "severity": "HIGH",
  "description": "Blizzard forecast indicates wind turbine curtailment within 4 hours. Pre-heat living modules and stage secondary generator.",
  "action_payload": {
    "target_equipment_id": 2,
    "action": "start_generator",
    "load_target_kw": 45.0
  }
}
```

---

### 3.3 Approve Recommendation
`POST /api/recommendations/{id}/approve`

Authorizes immediate execution of the recommended action.

#### Request Body
```json
{
  "notes": "Approved by Station Commander for upcoming blizzard."
}
```

---

### 3.4 Modify Recommendation
`POST /api/recommendations/{id}/modify`

Applies modified operational parameters prior to approval.

#### Request Body
```json
{
  "modified_payload": {
    "target_equipment_id": 2,
    "action": "start_generator",
    "load_target_kw": 35.0
  },
  "notes": "Modified target load down to 35 kW to preserve fuel."
}
```

---

### 3.5 Reject Recommendation
`POST /api/recommendations/{id}/reject`

Rejects recommendation with mandatory justification notes.

#### Request Body
```json
{
  "notes": "Secondary generator currently undergoing scheduled oil filter replacement."
}
```
